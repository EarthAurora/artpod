# ArtPOD — Creative Commerce OS

This is a public proof-of-concept dashboard for reviewing historical visual
assets before design or product work begins.

It demonstrates a deliberately limited workflow:

1. source intake;
2. rights and provenance review;
3. visual-library review;
4. opportunity, design, product, content, and experiment planning.

The data is a fixed snapshot of 22 Metropolitan Museum of Art collection
records selected from existing bounded `Islamic tile` review batches. Each
record links back to its institutional source. Public-domain routing is a
workflow classification for review, not legal advice or approval to use an
asset commercially.

## What this demo is not

- Not a live ingestion service or recurring scraper.
- Not a product store, marketplace integration, or automated publishing tool.
- Not a completed market-validation study.
- Not a commercial-use clearance system.

Museum photographs and collection scans are treated as source references, not
product artwork. Any future design, product, and publishing decision remains
subject to human review.
